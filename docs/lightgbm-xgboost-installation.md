# LightGBM and XGBoost Research Models

LightGBM and XGBoost are installed in the Ubuntu GoldcrestAI virtual environment. This repository integration keeps both as offline research candidates alongside Qwen. Installing a package does not train or qualify a model.

- LightGBM: structured-data research candidate.
- XGBoost: independent challenger.
- Qwen remains the language-model integration.
- `NO_TRADE` remains enforced until separately qualified.

Training requires an explicitly defined dataset, feature schema, target, prediction horizon, chronological split, and cost assumptions. Do not infer performance from synthetic fixtures.
